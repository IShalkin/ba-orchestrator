# NotebookLM Mind Map (6) — Business Analysis Techniques Analysis Guide

Источник: `NotebookLM Mind Map (6).png` (6592×4738 px). Расшифровка дословная.
Узлов: 27 = корень 1 + «Method Analysis Structure» 1 + разделов 8 + листьев 17.

Это шаблон (17 полей) для разбора любого метода БА. Карта 8 — заполненный по этому шаблону каталог из 13 методов (16 полей: поле Prerequisites там не заполнено).

- **Business Analysis Techniques Analysis Guide**
  - **Method Analysis Structure**
    - **Problem and Uncertainty Solved**
      - What problem does the method solve?
      - What type of uncertainty, error, or conflict does it reduce?
    - **Application Lifecycle Stage**
      - Discovery / elicitation / analysis / specification / prioritisation / validation / change management
    - **Inputs and Outputs**
      - Input: Business problem, stakeholder request, interview, process, documentation, user story, law, backlog, incidents
      - Output: Scope statement, stakeholder map, goal model, use case, SRS section, decision table, acceptance criteria, traceability matrix
    - **Stakeholders and Prerequisites**
      - Participants: Sponsor, business owner, SME, end user, BA, product manager, architect, developer, tester, compliance/legal
      - Prerequisites: Known, agreed, or prepared information before start
    - **Procedure and Diagnostic Questions**
      - Procedure: 3-10 action algorithm of order and decisions
      - Questions: Interview guides, workshop prompts, and diagnostic questions
    - **Artifacts, Examples, and Quality**
      - Artifacts: Template, diagram, catalog, table, model, decision record, specification
      - Example: Short realistic application example
      - Quality Check: Criteria, checklist, peer review, stakeholder walkthrough, prototype, test/acceptance example
    - **Risks, Limits, Alternatives, and Decisions**
      - Anti-patterns: False confidence, bureaucracy, or failure modes
      - Non-use: Low risk, known domain, urgent hypothesis, no access, high uncertainty, low team maturity
      - Alternatives: What to apply before, after, and instead
      - Decision Link: Scope, priority, architecture, release, acceptance, compliance
    - **AI Adaptation**
      - AI / Agentic: Roles, inputs, risks, human-in-the-loop, quality evaluation, guardrails, audit trail
