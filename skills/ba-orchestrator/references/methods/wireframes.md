# Wireframes

`T2 Situation Investigation and Elicitation › 2.8 Prototypes and Scenarios for Elicitation`

## Problem Solved

Creates simple 2D structural illustrations of screen layouts focusing on content allocation and navigation without visual style distractions, reducing UI design confusion.

## BA Lifecycle Phase

Define Requirements / Elicitation / Specification

## Input Artifacts

Scenarios, Storyboards, User analysis, functional specifications.

## Output Artifacts

Wireframe Diagrams (Hand-drawn low-fidelity or digital high-fidelity screen layout diagrams with content blocks, search fields, headers, footers, and links).

## Participants & Roles

BA, UX/UI Designer, Business Users, Developers.

## Prerequisites

Identification of screen functional requirements and key content types.

## Step-by-Step Procedure

Identify key content blocks, search areas, headers, and actions.
2. Draw 2D structural layout using grayscale boxes (use 'x' box for images).
3. Use generic single font sizes for headers/text.
4. Position primary content and navigation paths.
5. Review wireframe layout with users to agree content distribution.

## Analyst Questions & Prompts

Where should the primary content block sit? How much space should be allocated to search vs navigation? Is the contact form clearly positioned?

## Minimal Realistic Example

Drawing a grayscale web wireframe for a 'Contact Us' page showing header logo, global navigation bar, search box, map placeholder (box with x), and input form fields.

## Quality Criteria & Verification

Focuses purely on structural content layout and navigation pathways, omitting color, graphics, and specific fonts.

## Errors & Anti-Patterns

Adding colors, fancy fonts, and real graphics that distract users from structural layout feedback; treating wireframes as final graphic design.

## When NOT to Use

For non-visual back-end systems or when testing complex interactive micro-animations (use high-fidelity prototypes instead).

## Alternatives & Complementary Methods

Storyboarding, Prototyping, Personas.

## Supported Decisions

Screen layout sign-off, content prioritization, navigation structure approval.

## AI & Agentic Adaptation

AI sketching tools transform hand-drawn napkin wireframe sketches into clean digital UI layouts and responsive code templates.
