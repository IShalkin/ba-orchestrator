# Design Studio

`T2 Situation Investigation and Elicitation › 2.6 Group and Creative Sessions`

**Also described as:** Design Studio / Collaborative Ideation

## Problem Solved

Reduces solution bias, single-designer bias, and unviable UI designs; overcomes the tendency to accept the first obvious idea by exploring multiple creative solutions collaboratively.

## BA Lifecycle Phase

Elicitation / analysis / specification

## Input Artifacts

Problem definition, user personas, journey maps, design inspirations, constraints.

## Output Artifacts

Sketched UI concepts, consolidated solution wireframes, storyboarded user flows.

## Participants & Roles

Product Owner, UX Designer, Business Analyst, Developers, Testers, Business Stakeholders, End Users/Customers (optional).

## Prerequisites

Clear problem statement, defined target persona, sketching materials (paper, pens/markers), time-box.

## Step-by-Step Procedure

Invite cross-functional group (8–12 participants).
2. Present the business/user problem, persona, and inspirations.
3. Individual fast sketching session (e.g., 15 minutes).
4. Share sketches in small sub-groups (4 people) and give feedback based on problem fit.
5. Consolidate best ideas into a single combined sketch per group.
6. Present consolidated sketches to the whole team and synthesize into a final solution direction.

## Analyst Questions & Prompts

"How well does this sketch solve the target user's problem?", "How can we build on this idea?", "What is another completely different way we could approach this screen?"

## Minimal Realistic Example

A team of 8 (developers, UX, product owner) sketching 4 different layout variations for an online banking transfer interface, giving feedback, and merging the best security and usability elements into a unified layout sketch.

## Quality Criteria & Verification

Diversity of explored ideas; feedback focused on problem fit rather than personal aesthetic taste; consensus on consolidated design by the core discovery team.

## Errors & Anti-Patterns

Design by committee (compromising to make everyone happy instead of picking the best fit); letting HiPPOs dominate the sketching; critique focused on drawing skill rather than usability.

## When NOT to Use

Simple standard interface updates, well-established UI pattern implementations with no ambiguity.

## Alternatives & Complementary Methods

Solo UX sketching, Paper Prototyping, Wireframing, Rehearsal Mapping.

## Supported Decisions

UI/UX design direction, feature feasibility, interaction workflow acceptance.
