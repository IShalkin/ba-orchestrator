# RASCI Chart

`T3 Stakeholders › 3.2 Stakeholder Analysis and Mapping`

**Also described as:** RASCI charts

## Problem Solved

Maps stakeholder roles and responsibilities across project tasks or business processes, reducing role confusion, unassigned ownership, and overlapping authority.

## BA Lifecycle Phase

Consider Perspectives / Analysis / Specification

## Input Artifacts

Task list, process models, stakeholder list, job descriptions.

## Output Artifacts

RASCI Matrix (Tasks on vertical axis, Roles on horizontal axis, populated with R, A, S, C, I letters).

## Participants & Roles

BA, Project Sponsor, Project Manager, Operations Leads.

## Prerequisites

List of tasks/work areas and defined stakeholder roles.

## Step-by-Step Procedure

List tasks along matrix rows (using active verbs).
2. List stakeholder roles along matrix columns.
3. For each task, assign Responsible (R - owns/does work), Accountable (A - ultimate sign-off), Supportive (S - provides resources/help), Consulted (C - provides input), Informed (I - notified of outcome).
4. Verify matrix completeness.

## Analyst Questions & Prompts

Who is ultimately Accountable for this task? Who is Responsible for doing the work? Who provides Support? Who must be Consulted? Who needs to be Informed?

## Minimal Realistic Example

For the task 'Document Requirements', BA is Responsible (R), Sponsor is Accountable (A), Sales Clerk is Consulted (C), and Project Manager is Informed (I).

## Quality Criteria & Verification

Exactly one 'Accountable' role per task; at least one 'Responsible' role per task; balanced workload distribution across roles.

## Errors & Anti-Patterns

Assigning multiple Accountable roles to a single task; assigning too many Responsible roles; confusing Accountable (sign-off) with Responsible (execution).

## When NOT to Use

For micro-level internal algorithmic coding steps with a single developer.

## Alternatives & Complementary Methods

RACI, ARCI, Power/Interest Grid, User Analysis.

## Supported Decisions

Project governance definition, role design, approval workflows, communication routing.

## AI & Agentic Adaptation

Governance AI parses workflow models and project plans to draft RASCI matrices, highlighting tasks with missing or duplicate Accountable roles.
