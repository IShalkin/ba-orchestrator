# Personas

`T3 Stakeholders › 3.1 Stakeholder Identification`

## Problem Solved

Creates realistic fictional user archetypes to embody user goals, behaviors, and motivations, reducing selfish or biased user interface design assumptions.

## BA Lifecycle Phase

Consider Perspectives / Analysis / Elicitation / Specification

## Input Artifacts

User analysis, market analytics, stakeholder interviews, domain knowledge.

## Output Artifacts

Persona Profiles (1-2 page descriptions detailing demographics, professional background, motivations, tech comfort, preferences).

## Participants & Roles

BA, UX Designer, Business Users, Domain Experts.

## Prerequisites

Research into the target user/customer community.

## Step-by-Step Procedure

Research stakeholder user community.
2. Identify common behavioral patterns and characteristics.
3. Define 3-5 representative fictional personas.
4. Populate persona templates (Personal, Professional, Motivations, Dislikes, Tech literacy).
5. Use personas to evaluate proposed system designs, wireframes, and workflows.

## Analyst Questions & Prompts

Who is this user? What are their goals and frustrations? How tech-literate are they? Would 'Susan' find this screen layout intuitive?

## Minimal Realistic Example

Creating 'Susan', a 57-year-old busy Sales Manager who wants quick luxury purchases and hates low-value cheap gift items, to evaluate an e-commerce gift site.

## Quality Criteria & Verification

Personas represent research-backed archetypes rather than false user stereotypes or the analyst's personal preferences.

## Errors & Anti-Patterns

Creating too many personas (>5); treating personas as a static paper exercise without using them to validate actual screen designs.

## When NOT to Use

When designing fully automated back-end machine-to-machine interfaces with no human user interaction.

## Alternatives & Complementary Methods

User Analysis, Scenarios, Wireframes, Ethnographic Studies.

## Supported Decisions

UI/UX design choices, feature prioritization, accessibility specifications, value proposition alignment.

## AI & Agentic Adaptation

AI models generate synthetic user personas based on live customer behavioral analytics and simulate persona navigation through proposed wireframe prototypes.
