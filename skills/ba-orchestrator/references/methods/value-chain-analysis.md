# Value Chain Analysis

`T1 Strategy Analysis and Justification › 1.3 Current State, Capabilities and Gaps`

**Also described as:** Value chain analysis

## Problem Solved

Groups organizational activities into Primary (Inbound logistics, Operations, Outbound logistics, Marketing/Sales, Service) and Support activities, reducing siloed operational thinking.

## BA Lifecycle Phase

Analyse Needs / Organisation Modelling

## Input Artifacts

High-level business architecture, departmental workflow summaries, value propositions.

## Output Artifacts

Value Chain Diagram showing primary and support activity chains.

## Participants & Roles

BA, Enterprise Architect, Operations Director, Business Process Owner.

## Prerequisites

High-level understanding of the enterprise business model.

## Step-by-Step Procedure

Identify core 'Operations' activity (the main value delivery).
2. Identify 'Inbound logistics' (inputs/preparation).
3. Identify 'Outbound logistics' (delivery/distribution).
4. Identify 'Marketing and Sales' (promotion/registration).
5. Identify 'Service' (post-sales support).
6. Identify 'Support activities' (Procurement, Tech, HR, Infrastructure).
7. Link primary activities sequentially.

## Analyst Questions & Prompts

What is our primary operations activity? What inbound activities prepare for this? How do we distribute outputs? How do we market and sell? What support functions enable these primary activities?

## Minimal Realistic Example

An examination body maps primary activities: Research qualification requirements & Promote qualifications (Sales) -> Define syllabus, Write exams, Set schedule (Inbound) -> Examine candidates (Operations) -> Issue results (Outbound) -> Handle appeals (Service).

## Quality Criteria & Verification

Complete end-to-end representation of primary activities delivering customer value, clearly distinguished from support functions.

## Errors & Anti-Patterns

Applying rigid manufacturing value chain labels to service organizations without adapting the category definitions.

## When NOT to Use

When analyzing micro-level algorithmic system code or localized single-task desk procedures.

## Alternatives & Complementary Methods

Value Streams, Capability Modelling, Business Activity Modelling, Organization Diagram.

## Supported Decisions

Process hierarchy structuring, process improvement prioritization, target operating model design.

## AI & Agentic Adaptation

Enterprise process mining tools auto-map cross-departmental workflows into high-level Primary and Support Value Chain architectures.
