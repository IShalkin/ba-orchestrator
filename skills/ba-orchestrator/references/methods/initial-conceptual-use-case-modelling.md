# Initial (Conceptual) Use Case Modelling

`T5 Requirements Specification › 5.2 Use Cases and Scenarios`

**Also described as:** Initial Use Case Modeling (Conceptual Use Cases)

## Problem Solved

Reduces ambiguity regarding system capabilities and aligns high-level functional expectations across business and technical teams.

## BA Lifecycle Phase

Elicitation / analysis

## Input Artifacts

Context diagram, Vision Document, stakeholder analysis, actor glossary.

## Output Artifacts

Initial Use Case Model, Initial Use Case Diagram, Initial Use Case Descriptions (narrative paragraphs).

## Participants & Roles

Sponsor, SME, Primary Actors, BA/System Analyst, Architect.

## Prerequisites

System boundary defined; major primary actors identified.

## Step-by-Step Procedure

Review primary actors and ask what goals/services they require from the system.
2. Name each use case with an active verb-noun phrase from the actor's perspective.
3. Draft a 2-4 sentence narrative description summarizing the goal and main interaction.
4. Create initial Use Case Diagram linking actors to use cases.
5. Conduct a workshop with stakeholders to review and validate.

## Analyst Questions & Prompts

What measurable value does the actor expect? What business event triggers this interaction?

## Minimal Realistic Example

Use Case 'Submit Loan Request': Applicant submits an online application. System validates data, pulls credit report, and assigns initial score.

## Quality Criteria & Verification

Stakeholder walkthrough; verify that every use case provides measurable value to at least one actor and traces to a business goal.

## Errors & Anti-Patterns

Naming use cases as functional tasks ('Enter Data') rather than goal-driven business events ('Apply for Loan').

## When NOT to Use

Systems with no functional user interaction (e.g., pure batch computation algorithms).

## Alternatives & Complementary Methods

User Stories (Extreme Programming), Feature Lists, Business Process Diagrams.

## Supported Decisions

Scope, initial release planning, architectural scoping.
