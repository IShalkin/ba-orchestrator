# Tasks and Support

`T4 Modelling and Analysis › 4.1 Business Processes and User Work`

**Also described as:** Tasks & Support

## Problem Solved

Balances domain-level user task demands against candidate software product features, bridging problem specification and solution evaluation.

## BA Lifecycle Phase

analysis

## Input Artifacts

Domain task descriptions, stakeholder problem lists, vendor proposals.

## Output Artifacts

Two-column task tables detailing domain sub-tasks/problems on the left and proposed/agreed software support on the right.

## Participants & Roles

BA, SME, product vendor/developer, customer project team.

## Prerequisites

Domain task identification and SME availability.

## Step-by-Step Procedure

Document domain sub-tasks and operational problems in the left column using imperative language.
2. Detail task triggers, frequency, and critical situations.
3. Provide candidate product support features or example solutions in the right column.
4. Submit table to vendors/developers during tender or design phases.
5. Evaluate proposals and convert the right column to agreed project commitments.

## Analyst Questions & Prompts

What is the main problem with how you do this step today? How could a computer best support you here?

## Minimal Realistic Example

Sub-task:
1. Find room. Problem: Guest wants neighboring rooms. Example Solution: System shows free rooms on visual floor map.

## Quality Criteria & Verification

Stakeholder review, vendor proposal scoring, task walkthrough verification during acceptance testing.

## Errors & Anti-Patterns

Writing traditional feature specifications directly inside the left column; failing to update column headings during contract lifecycle.

## When NOT to Use

Pure technical sub-contracting projects where no human interface exists.

## Alternatives & Complementary Methods

Task Descriptions, Features from Task Descriptions, Use Cases.

## Supported Decisions

Vendor selection in tenders, COTS fit-gap analysis, scope vs. cost trade-off decisions.

## AI & Agentic Adaptation

Auto-populate candidate technical solutions in the right-hand column by prompting AI agents with domain sub-tasks and vendor feature sheets.
