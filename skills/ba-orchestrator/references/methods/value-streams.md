# Value Streams

`T1 Strategy Analysis and Justification › 1.3 Current State, Capabilities and Gaps`

**Also described as:** Value streams

## Problem Solved

Models end-to-end sequential stages that deliver value to stakeholders, reducing siloed process optimization that fails to deliver end-to-end value.

## BA Lifecycle Phase

Analysis / Specification / Change Management

## Input Artifacts

Stakeholder perspectives, Value Propositions, Capability Model.

## Output Artifacts

Value Stream Model depicting sequential value stages, trigger events, and enabling business capabilities.

## Participants & Roles

BA, Business Architect, Enterprise Architect, Customer Experience Lead, Sponsor.

## Prerequisites

Identification of target stakeholder groups and their perceived value propositions.

## Step-by-Step Procedure

Identify the primary target stakeholder and their desired value.
2. Work backward to define high-level sequential stages required to deliver that value.
3. Identify the triggering stakeholder event.
4. Map required enabling business capabilities to each stage.
5. Verify value accrual at each stage.

## Analyst Questions & Prompts

What value does the stakeholder expect? What sequential stages must occur to realize this value? What capability enables each stage?

## Minimal Realistic Example

A passenger's value stream for 'Fly to holiday destination' includes stages: Park car -> Check in & bag drop -> Clear security -> Clear passport control -> Board flight -> Clear immigration -> Pick up bags.

## Quality Criteria & Verification

Each stage must incrementally add value from the stakeholder's perspective; stages are high-level and distinct from low-level detailed process steps.

## Errors & Anti-Patterns

Confusing value stream stages with detailed operational workflow diagrams; burying value streams inside internal departmental silos.

## When NOT to Use

For micro-level task step analysis or purely technical system integration mapping.

## Alternatives & Complementary Methods

Value Stream Mapping (Lean), Value Chain Analysis, Capability Modelling, Business Process Modelling.

## Supported Decisions

Customer experience optimization, process re-engineering scope, capability investment prioritization.

## AI & Agentic Adaptation

Process mining agents analyze cross-system transaction logs to reconstruct real-world value stream execution times and friction points.
