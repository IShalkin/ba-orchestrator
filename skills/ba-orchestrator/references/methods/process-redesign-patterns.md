# Process Redesign Patterns

`T4 Modelling and Analysis › 4.1 Business Processes and User Work`

**Also described as:** Process redesign patterns

## Problem Solved

Provides four structured analytical approaches (Reengineering, Simplification, Value-add analysis, Gaps/Disconnects) to guide process improvement and elimination of waste.

## BA Lifecycle Phase

Analyse Needs / Change Identification / Process Design

## Input Artifacts

'As Is' Business Process Models, Task analysis records, Customer Value Propositions.

## Output Artifacts

Redesigned 'To Be' Business Process Models, process waste elimination report.

## Participants & Roles

BA, Business Process Owner, SMEs, Operations Lead.

## Prerequisites

Documented 'as is' process models and identified customer value targets.

## Step-by-Step Procedure

Select redesign pattern(s).
2. For Reengineering: discard current process, work backward from end goals/events using technology.
3. For Simplification: examine tasks for redundancy, duplication, and bottlenecks.
4. For Value-add: classify tasks as Value-adding, Value-enabling, or Non-value-adding (eliminate/streamline non-value tasks).
5. For Gaps/Disconnects: analyze communication handoffs and conflicting metrics between actors.

## Analyst Questions & Prompts

If we started from scratch today, how would we achieve this goal (Reengineering)? Is this step redundant (Simplification)? Would the customer pay for this step (Value-add)? Where do handoff failures occur (Disconnects)?

## Minimal Realistic Example

Applying Value-add analysis to an invoice approval process: classifying 'Manager Sign-off' on small invoices as Non-value-adding control waste, replacing it with random sampling.

## Quality Criteria & Verification

Demonstrated reduction in process cycle time, cost, or handoff errors while preserving or enhancing end customer value.

## Errors & Anti-Patterns

Automating an inherently flawed, redundant process without simplifying it first; eliminating essential compliance/control tasks during aggressive value-add trimming.

## When NOT to Use

When process rules are strictly mandated by external statutory laws that forbid procedural alterations.

## Alternatives & Complementary Methods

Business Process Reengineering (BPR), Lean Value Stream Mapping, Gap Analysis.

## Supported Decisions

To-be process model design, IT feature automation scope, operational waste elimination.

## AI & Agentic Adaptation

Process mining AI applies Value-add and Disconnect patterns to real-time event logs to automatically highlight redundant steps and handoff bottlenecks.
